# Mission 1: Know your computer

## 1. Task / objective
Explain how a computer takes input, processes it, produces output and stores results (IPOS), and identify hardware, software and everyday computer systems.

## 2. Work completed

### Task 1.1: IPOS for one activity
Activity chosen: Writing and saving a document.

| Stage | What happens in my example | Hardware / component |
|---|---|---|
| Input | I type words using the keyboard. | Keyboard |
| Processing | The computer processes my keystrokes in the word processor. | CPU / processor |
| Output | The document text appears on the screen. | Monitor / display |
| Storage | I save the document as a file. | SSD / storage drive |

The keyboard sends my words to the computer. The processor handles them, and the display shows the document. When I save it, the file is stored on the computer's storage drive.

## 4. My understanding
IPOS means input, processing, output and storage. A computer receives input, processes it, produces output and can store the results. Hardware is the physical equipment. Software is the set of programs that runs on the hardware. System software manages the computer, while application software helps users perform tasks.
