## Glossary
- **Repository:** A project folder whose changes Git tracks.
- **Git:** A version control tool that records changes to files.
- **GitHub:** A website for hosting Git repositories and collaborating.
- **Branch:** A separate line of work in a repository.
- **Commit:** A saved snapshot of changes.
- **Push:** Sending local commits to a remote repository.
- **Pull request:** A proposal to review and merge changes from one branch into another.
- **Merge:** Combining changes from one branch into another.
